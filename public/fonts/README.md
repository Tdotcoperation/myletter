# 교보 손글씨 2025 이유빈

이 경로에는 글꼴 파일이 포함되어 있지 않습니다.

교보 손글씨 2025 이유빈은 사용·임베딩·파일 재배포 조건을 확인한 후 적법한 방법으로 파일을 준비해야 합니다. 라이선스를 확인하고 웹 임베딩이 허용된 경우에만 `kyobo-yubin.woff2`를 여기에 추가하세요. 이 폰트가 없으면 포스트잇은 브라우저 기본 손글씨 계열 대체 글꼴로 나타납니다.
